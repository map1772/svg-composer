# Изоконструктор

React + TypeScript + Vite редактор изометрических композиций на основе реальных PNG заказчика.

## Запуск

```bash
npm install
npm run dev
npm run build
```

На Windows с ограниченной политикой PowerShell можно использовать `npm.cmd run build`.

## Архитектура

- `src/data/assetLibrary.ts` хранит каноническую карту `assetId → main/background → L/S`, реальные размеры PNG и исходные UUID-файлы.
- `src/data/compositionPresets.ts` хранит шесть эталонных манифестов. Координаты и ширина нормализованы относительно базового размера эталона.
- `src/data/palettes.ts` содержит цвета, снятые с исходных палитр заказчика, и размеры холстов 1:1, 16:9, 9:16.
- `src/components/SceneCanvas.tsx` выполняет contain-fit адаптацию сцены и drag-and-drop.
- `src/components/SceneObject.tsx` рендерит PNG через SVG `<image preserveAspectRatio="xMidYMid meet">` без растягивания по одной оси.
- `src/components/BackgroundTemplate.tsx` содержит три фоновые геометрии: линии и блики, угловая плоскость, чистый фон.
- `src/components/PresetGallery.tsx` отображает шесть эталонов и отдельный сброс каждого пресета.
- `src/lib/exportSvg.ts` формирует SVG с `viewBox`, `clipPath` и внешними или встроенными PNG.
- `src/lib/sceneGeometry.ts` отвечает за преобразование координат и расчёт совпадения по позиции и размеру.

## Ассеты

- Неизменённые исходники заказчика: `public/assets/исходные png/`.
- Эталонные композиции: `public/assets/примеры композиции/`.
- Канонические рабочие варианты: `public/assets/library/`.
- Инвентаризация 26 исходников: `docs/asset-inventory.md`.
- Машиночитаемые размеры, alpha и bounding box: `docs/source-asset-inventory.json`.

`scripts/build-asset-library.ps1` собирает 40 вариантов PNG. L сохраняет исходное разрешение, S использует половинное разрешение при том же aspect ratio. Для отсутствовавших в поставке цветного пазла, фоновой книги и фоновой монеты скрипт создаёт пиксельные производные, сохраняя форму, alpha, контуры и тени исходников.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-asset-library.ps1
```

## Модель сцены

Объект хранит:

```ts
{
  assetId,
  role,
  x,
  y,
  width,
  rotation,
  opacity,
  zIndex,
  flipX
}
```

`x`, `y` и `width` нормализованы относительно базового эталона. При смене формата применяется единый коэффициент contain-fit, поэтому пропорции объектов и расстояния между ними не искажаются. Свободного масштабирования в интерфейсе нет.

## Возможности

- шесть эталонных пресетов с точным составом, ролями и порядком слоёв;
- drag-and-drop с разрешённым выходом объектов за границы холста;
- замена main/background реальным ролевым PNG;
- замена L/S отдельным PNG без изменения геометрии объекта;
- быстрые повороты -15°, 0°, +15°, отражение и управление слоями;
- сравнение эталона и текущей сцены с оценкой по координатам и ширине;
- палитры Lavender, Peach, Mint и три фоновые геометрии;
- загрузка и безопасное отображение пользовательского SVG;
- автономный экспорт SVG со встроенными PNG data URL;
- сборка по смысловым тегам и списку компонентов.

## Проверка

```bash
npm run build
```

Перед выпуском проверяются все шесть пресетов, форматы 1:1, 16:9, 9:16, смена L/S и ролей, drag-and-drop, отсутствие битых PNG-путей и открытие экспортированного SVG в браузере.
