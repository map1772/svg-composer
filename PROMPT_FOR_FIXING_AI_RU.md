## Главная проблема

Текущие композиции собираются приблизительно и не совпадают с эталонами. Нужно добиться визуального совпадения с шестью PNG-примерами. Нельзя использовать приблизительную раскладку «примерно в тех же местах». Нужно воспроизвести состав, относительные координаты, масштаб, повороты, выход объектов за границы, порядок слоев, фоновые объекты, прозрачность и цветовую схему.

## Эталонные композиции

В папке `примеры композиции` лежат 6 файлов. Сначала открой и проанализируй каждый файл, составь для него JSON-манифест:

```ts
type CompositionManifest = {
  id: string;
  format: 'square' | 'wide' | 'tall';
  backgroundTemplate: 'lines' | 'corner' | 'clean';
  backgroundColor: string;
  objects: Array<{
    assetId: string;
    role: 'main' | 'background';
    x: number;
    y: number;
    width: number;
    rotation: number;
    opacity: number;
    zIndex: number;
  }>;
};
```

Используй этот манифест как источник истины для пресетов. Не вычисляй координаты заново при каждом рендере и не подменяй объекты нарисованными примитивами.

## Обязательные исправления

1. Сохрани реальные PNG-ассеты заказчика. Не перерисовывай их упрощенными SVG-формами.
2. Сделай отдельную карту `assetId -> main/background -> L/S`, чтобы у каждого объекта были правильные версии.
3. Исправь ошибочные соответствия файлов. Нельзя использовать PNG телефона вместо пазла, монохромный пазл вместо цветного или объект с неверной ролью.
4. Для каждого объекта используй `object-fit: contain` или SVG `<image preserveAspectRatio="xMidYMid meet">`, не растягивай объект по одной оси.
5. Сохрани канонические пропорции объектов. Пользователь может менять только координаты, угол, роль и порядок слоя.
6. Реализуй точный z-index. Фоновые объекты должны быть ниже главных, книга/папка могут быть носителем, телефон/пазл/ручка должны лежать поверх.
7. Переключение `main/background` должно заменять ассет, а не просто уменьшать opacity.
8. Переключение `L/S` должно менять ассет на соответствующую детализированную версию и сохранять x/y/rotation/role/zIndex.
9. Пресеты должны воспроизводить 6 эталонов один в один. Для каждого пресета добавь кнопку «Сбросить к эталону».
10. Добавь режим сравнения: слева эталонный PNG, справа текущая композиция; процентное совпадение считать по размеру и позициям объектов, а не по случайному текстовому описанию.
11. Добавь drag-and-drop перемещение объектов по холсту, но не разрешай свободное масштабирование объектов.
12. Добавь точные быстрые повороты `-15°`, `0°`, `+15°`, отражение по изометрической оси и управление слоями.
13. Экспортируй чистый SVG с `viewBox`, `clipPath` и корректными `<image href="...">`. Если нужен self-contained экспорт, встраивай PNG как data URL.
14. Для фона используй три отдельные геометрии: линии и блики, угловая плоскость, чистый фон. Цвета должны брать значения из активной палитры.
15. Не ломай текущие рабочие функции: выбор размера, формата, палитры, загрузка SVG, очистка сцены, документация и экспорт.

## Как работать

1. Сначала изучи весь `src/main.tsx`, `src/styles.css`, `README.md` и обе папки ассетов.
2. Составь таблицу соответствий всех PNG: имя файла, объект, роль, размер, формат, прозрачность, назначение.
3. Проверь изображения программно: реальные размеры, alpha-канал, bounding box непрозрачных пикселей.
4. Создай модуль `src/data/assetLibrary.ts` и модуль `src/data/compositionPresets.ts`. Не держи большой asset map внутри React-компонента.
5. Вынеси рендер сцены в компоненты `SceneCanvas`, `SceneObject`, `BackgroundTemplate`, `PresetGallery`.
6. Для каждого из 6 эталонов создай точный манифест с нормализованными координатами 0..1 и базовым размером.
7. Реализуй адаптацию манифеста к `1:1`, `16:9`, `9:16` без изменения относительных пропорций объектов.
8. После правок проверь все 6 эталонов визуально, затем запусти `npm run build`.
9. Исправь все TypeScript-ошибки и предупреждения, проверь отсутствие битых путей к PNG.

## Критерии готовности

- `npm run build` завершается успешно.
- Все реальные PNG находятся в `public/assets` и используются приложением.
- В каждом пресете совпадают объектный состав, роли, порядок, относительные размеры, повороты и фон.
- Пропорции объектов нельзя нарушить пользовательским интерфейсом.
- Нет перерисованных placeholder-объектов вместо ассетов.
- Экспорт SVG открывается в браузере и сохраняет сцену.
- README описывает фактическую архитектуру после исправлений.

Не ограничивайся объяснением. Внеси правки в файлы проекта, проверь результат и в конце сообщи список изменённых файлов и результат `npm run build`.
